# G4F-WM-009: Baseline Financial State Predictor

This task trains a reproducible logistic-regression baseline to predict a
synthetic future stress/default label and compares it with a majority-class
naive predictor. The frozen 60-entity, 36-month input panel was generated by
the WM-008 synthetic panel generator; the evaluator itself uses only files in
this folder.

## Target and features

- **Target:** `default_in_horizon`, 1 if the synthetic latent stress process
  crosses its threshold at any point in the next three monthly periods, else 0.
- **Features available at prediction time:** `utilisation`, `days_past_due`,
  and `income_ratio`.
- **Excluded:** the target itself and `recovery_amount`, which is only defined
  after the future outcome. The source also has a `dpd_observed_at` timestamp;
  it confirms that the days-past-due observation is known before the prediction
  timestamp.
- **Split:** chronological train/validation/test with rows purged when their
  three-month target window crosses the next split boundary. The same synthetic
  entities can appear in multiple time periods; see the model card.

## Run

From this folder:

```bash
python -m pip install -r requirements.txt
python -m evaluation.run_baseline
```

The evaluation writes `reports/baseline_metrics.json` and
`reports/run_manifest.json`. Use `--config`, `--data`, and `--output-dir` to
select alternate inputs or paths. To rebuild the frozen panel sample, run
`python data/build_sample_panel.py` from this folder; that rebuild step uses
the sibling WM-008 generator. Routine training/evaluation does not need WM-008
because the panel CSV is checked in.

## Outputs

- Overall validation and test metrics for logistic regression and the
  training-split majority-class baseline.
- Test metrics by calendar quarter and synthetic utilisation band.
- Sample counts and positive rates for every reported group.
- Null metric values when a subgroup lacks the classes needed for a defined
  AUC or balanced-accuracy calculation.
- Dataset/configuration hashes and dependency versions for reproduction.

This synthetic task demonstrates a modeling and evaluation workflow. It is not
a credit score, a prediction about real customers, or evidence of production
performance.
