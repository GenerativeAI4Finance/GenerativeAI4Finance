# G4F-WM-005: Dataset Provenance, Licensing, and Limitations

This folder provides a reusable dataset-card template and a completed card for
the synthetic financial-state reconstruction materials produced by G4F-WM-001
through G4F-WM-004.

## Files

- `dataset_card_template.md` — blank card to complete for a new dataset.
- `financial_state_reconstruction_dataset_card.md` — completed card describing
  the currently available WM-001–004 synthetic records, generated datasets,
  and validation fixtures.

The card treats each data source as synthetic, public, licensed, or
user-contributed, and records provenance and access dates where applicable.
It distinguishes repository licensing from data provenance and does not claim
that synthetic examples are empirical evidence.

## Use

Copy the template for a new dataset, fill every section, and mark fields
`Not applicable` or `Unknown` with a reason when appropriate. Update the
version history whenever the data, generator assumptions, provenance, or
license changes. Review the completed card whenever a dataset version is
released.
